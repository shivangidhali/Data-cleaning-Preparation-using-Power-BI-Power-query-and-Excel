# Data-cleaning-Preparation-using-Power-BI-Power-query-and-Excel

## Objective
I cleaned and transformed a poorly structured sales dataset using Power BI Power Query.
Handled duplicates, null values, and unstructured columns to make the data analysis-ready.
Improved data readability and usability by restructuring the dataset into a clean, normalized format.

## Problem Statment:
  - Repeated column titles, making the data difficult to read and interpret
  - Sales values spread across multiple columns instead of a simple raw-wise structure
  - Pre-calculated totals mixed with raw data, increasing risk of double counting
  - No clear definition of what one raw represents causing confusion during analysis
  - Data structure not suitable for reporting or dashboard creation.

## The Data cleaning steps I applied:

   ✔ First Remove Duplicates and null values
✔ Keep first 2 Rows for categorization properly the data. 
✔ Transposed the Table, this is often necessary when data is store in inconvenience layout. 
✔ Then field down the data and merged the column.
✔ After that in the main data, I used Append query and then use first row as a Header. 
✔ Changed Data Type and Unpivoted the columns. 
✔ Then split the merged column by Delimiter.
✔ After All changed the Data type properly as per columns Data and Renamed columns name for better readability.

## Conclusion
“I transformed a poorly structured sale
dataset into an analysis-ready format using Power BI Power Query by removing irrelevant data, restructuring columns, and standardizing values.”
